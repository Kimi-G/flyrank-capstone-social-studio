# Social Media Studio

FlyRank Backend Track Capstone.

Social Media Studio turns one stored blog post into platform-specific social media variants, supports human review, schedules approved variants, and publishes each scheduled item through a configurable publisher adapter.

## Current Status

Phase 1 — Design.

See [DESIGN.md](DESIGN.md) for the initial architecture.

## Planned Stack

- Node.js
- Express
- SQLite
- BullMQ + Redis
- Mastodon real publisher
- Mock X publisher
- Mock LinkedIn publisher
